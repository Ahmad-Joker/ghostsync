This page is a test harness (not an application UI). It exposes window.__gs for the Playwright acceptance suite. Readiness is signalled by window.__gs being defined; tests await real lifecycle events (open resolved, flush resolved, transaction oncomplete). Offline-asset readiness is surfaced separately on window.__gsOffline and mirrored to the #offline-status panel and the <html data-offline-state> attribute.
